# MR-Qayamat

Qayamat ki Nishaniyan - Quran aur Hadees ki Roshni Mein

## Is Project ke Baare Mein
Is website ka maqsad logon ko Qayamat ki choti aur bari nishaniyon ke baare mein sahi maloomat dena hai.

## Website Mein Kya Hai?
- Home Page
- Choti Nishaniyan
- Bari Nishaniyan (10 Bari Nishaniyan)
- Quran aur Hadees ki Roshni Mein

## Website Kaise Chalayein?
1. Is repo ko download karein ya clone karein
2. `index.html` file ko browser mein kholein
3. Bas! Website chal jayegi.

Live Website: https://muzamilaman.github.io/MR-Qayamat/
